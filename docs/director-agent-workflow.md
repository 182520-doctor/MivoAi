# 导演 Agent 纯文本工作流

## 目标

先不接入图片、视频、多模态模型，让 Agent 通过纯文本完成导演前期工作：把用户的模糊创意推进成可执行的完整剧本、分镜方向和修改建议。

## 输入

用户可能只提供一句创意，例如：

- 一个雪山求生故事
- 一个猫咪宇航员短片
- 一个产品广告片想法

Agent 需要判断信息是否足够，而不是机械套模板。

## 交互策略

1. 信息不足时，最多提出 3 个关键问题。
   - 片长或媒介：15 秒广告、1 分钟短片、3 分钟剧情短片等
   - 类型和情绪：喜剧、悬疑、治愈、燃向、荒诞等
   - 必须出现的角色、产品、场景或结尾

2. 信息基本足够时，直接输出第一版完整方案。

3. 用户继续补充时，Agent 按已有版本迭代，不重复从零开始。

## 输出结构

第一版建议固定输出以下内容：

1. 创意定位
2. 目标受众与片长
3. 核心冲突
4. 人物设定
5. 故事结构
6. 完整剧本正文
7. 关键镜头与场景调度
8. 声音、节奏和情绪设计
9. 下一步可修改方向

## 思考过程展示

页面中的“思考过程”不展示模型隐藏推理，只展示产品层可见工作流：

- 正在拆解创意核心
- 正在判断人物关系
- 正在规划情绪弧线
- 正在组织剧本输出格式

Codex App Server 如果返回公开 reasoning summary，后端会合并到思考过程里；如果只返回英文短摘要，后端会本地化成中文展示。

## 当前边界

- 不调用生图模型
- 不调用视频模型
- 不生成真实素材
- 不读写用户文件
- 只做文本创作、剧本、分镜草案和导演说明

## 后续扩展

后面接入多模态模型时，可以把这条文本工作流继续作为上游：

1. 剧本
2. 分镜表
3. 每镜头画面提示词
4. 图片生成任务
5. 图生视频任务
6. 成片资产管理
